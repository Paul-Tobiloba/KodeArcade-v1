# Grade 1 Sequences media

`public/lessons/grade-1-sequences.webm` is an original, silent 16-second diagram video generated by `scripts/render-sequence-lesson.mjs`, using browser Canvas and MediaRecorder. No external footage, soundtrack, stock asset or AI-generated image is included. The diagram teaches a five-by-five grid, right/right/up and ordered movement; the marker is labelled Byte, not a replacement character illustration.

English WebVTT captions are in `public/lessons/grade-1-sequences.vtt`. The topic journey provides the same explanation as readable text and opt-in device read-aloud. Reviewing the text alternative counts equally toward introduction evidence. This is one starter lesson, not a production video library. Rebuild the binary with `node scripts/render-sequence-lesson.mjs` using an installed Playwright Chromium (set `PLAYWRIGHT_BROWSERS_PATH` if required).
