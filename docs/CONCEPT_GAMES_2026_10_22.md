- **Secret Gates:** actual Boolean evidence controls neutral/true/false switch lenses and separate gate-door leaves. - **Robot Workshop:** definitions, actual calls, numeric arguments, returned values and ordered SHOW output drive the reusable machine. Repeated/nested calls retain their real names/inputs and the original output sequence. Battery pictures are bounded to eight, with an explicit extra-count label; the numeric label and output sequence retain the actual values.
- **Results:** native keyboard-operable disclosure, closed by default, keeps the exact goal, score/calls, typed output, expression tree, trace and evaluation message. Escape closes it and returns focus to its summary. The scene no longer leads with the debug table.
- **Controls:** existing Play/Stop and reset handlers are reused. Reset keeps the code. Mission changes remount scene-local disclosure/art state. No additional direct keyboard capture, game timers, rewards or completion rules were added.

`src/conceptTrace.ts` defines optional ephemeral execution evidence. `src/conceptRuntime.ts` snapshots it on existing instruction frames without adding execution steps, evaluating skipped branches, changing allowlists or persisting traces as learner progress.
