# Operators, Boolean logic and functions — 16 October 2026

Owner direction: quizzes must assess the topic being taught, then implement operators/Boolean logic followed by functions. This is a bounded extension of the existing Grades 3–6 workspace, not a replacement learning platform or completion of the master curriculum.

## Available content

Three modules, in order after Variables: **Operators → Boolean logic → Functions**. Each has six authored activities per grade (72 new activities total), topic prose/worked examples/read-aloud, progressive real Blockly blocks, bounded Python-style Text in Grades 5–6, authored on-device Byte help and five concept questions. Current counts are 86 core challenges plus a project, and twelve quizzes, in Grades 3–6. Grades 1–2 remain 20/30 plus a project and 3/4 quizzes. Earlier activities, geometry, indices, code, completions and best stars are retained; new mission IDs append to the existing array and receive no inferred completions.

- Operators: operands/expressions, addition/subtraction/multiplication, grouping and precedence, stored-value reads. Division starts in Grade 4; remainder in Grade 5. Grade 6 composes the operations. Text grouping maps to nested value blocks rather than evaluating arbitrary code.
- Boolean logic: numeric comparisons, Boolean literals, AND/OR/NOT, compound conditions and IF/ELSE from Grade 4. Grade 3 comparisons use equality/less/greater; inclusive/inequality comparisons start in Grade 4. AND/OR short-circuit using Boolean operands, not Python’s general truthiness or operand-return behaviour.
- Functions: Grades 3–4 define/call named groups, reuse the whole body, call from bounded loops and decompose work. Grades 5–6 add one local numeric parameter named value, call arguments and numeric return values. Grade 6 adds composed arguments and helper calls. A definition does not execute its body. RETURN ends the current call and sends its result to the caller; SHOW displays output without returning it.

The stage is a results lab rather than a route: it displays the target, current score when relevant, ordered output, call count and execution trace. The guide/editor/Play placement, rewards, preferences and autosave are reused. Blockly includes typed number/Boolean sockets and real expression reporter blocks, not text fields that claim to be code blocks. The keyboard builder adds instructions to main/DO/ELSE, fills value inputs, edits fields and deletes blocks; Undo and native dragging remain available. The palette stays vertical on desktop/tablet and horizontal above the canvas on phones.

## Runtime boundary

Only explicitly supported syntax is parsed into Blockly state; no eval, imports, arbitrary attribute access, strings, indexing, arbitrary Python or remote code execution. Existing movement, drawing and data interpreters retain their earlier grammar and semantics. Concept code runs only in concept missions. A run starts with score unset, no outputs and no definitions.

Limits: 10,000 source characters, 100 nonempty lines, 100 tokens/500 characters per expression, twelve expression nesting levels, 24 blocks including value blocks (Text compiles against the same budget), 500 operations, 120 trace frames, 24 output values, finite numbers within ±1000, repeats 2–5, three nested instruction groups, four distinctly named definitions and at most three call levels in Grade 6. Recursion and redefining functions are rejected. Function parameters are per-call; global score assignment inside a function is deliberately unsupported. Function return values are numeric, not general objects/Booleans. Class systems, general local variables, arbitrary parameter names, closures, while loops, strings, events and integrated game capstones are not added.

Operations and comparisons use type checks; invalid number/Boolean connections report a readable type mismatch. Division by zero and values exceeding bounds fail without awarding completion. Remainder follows Python’s divisor-sign rule for negative values. Required operators/constructs and output/score checks prevent a literal final answer from satisfying a task that asks for a particular coding concept. Authored help remains on-device, and the private adult AI pilot is disabled for these new topic keys. No new learner-facing AI access is enabled.
