# Robot Rescue learning workspace

Mode: Operate. Deliver the approved mission flow directly in code, using the existing KodeArcade brand guide. The Impeccable launcher failed; project context was read directly. Parent company design files are not this app's design authority.

## Direction contract

THESIS: Place the program beside its visible result so every edit can become an understandable experiment.

OWN-WORLD: Midnight navigation, cloud reading surfaces, violet actions, teal movement blocks, yellow destination. Clear system typography follows the brief's low-bandwidth fallback. Crisp board geometry is functional game content.

STORY: Pick a mission, add instructions, run the robot, inspect feedback, ask for a hint, revise, and choose a next step. No compulsory account or diagnostic.

FIRST VIEWPORT: A compact brand bar and mission navigation; the main area holds a mission title and three working areas: robot stage on the left, Blockly palette in the middle, and the snapping code canvas on the right. Run is immediately below the canvas. The signature interaction highlights the executing block as the robot moves. Mouse and touch dragging are explicit user requirements. Narrow screens put the stage above the palette/canvas pair.

FORM: Brief-pinned educational coding workspace. No random concept selection applies to this specific working surface. Mobile stacks the board and editor while retaining mission navigation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
