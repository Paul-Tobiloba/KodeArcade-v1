# Class lifecycle extension

Mode: Operate. Local extension of the established teacher workspace; no new visual world, artwork or global token changes.

## Direction contract

THESIS: End-of-term cleanup pauses a classroom without erasing a child's work; avoid a destructive Delete class action.

OWN-WORLD: Inherit the white account workspace, purple/lavender controls, Fredoka headings, system-font utility copy and native details/confirmation controls.

STORY: Teachers filter Active/Archived classes, open a class, read the consequences, confirm Archive, and can restore it later. Reports remain readable. Archived classes cannot accept student logins, progress saves, roster edits or assignment changes.

FIRST VIEWPORT: The existing heading and class list remain. A labelled filter row precedes the table. A compact archive notice/action sits below classroom metadata and above reports; no modal on entry or extra decoration. Long tables scroll within their labelled region on phones.

FORM: Narrow code-led extension; no seed or comp required. Signature interaction is explicit confirmation before pausing access, followed by an actionable preserved-records state. Existing focus and reduced-motion rules apply.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
