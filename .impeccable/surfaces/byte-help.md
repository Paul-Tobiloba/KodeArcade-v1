# Ask Byte — learning-workspace extension

## Direction contract

THESIS: Help a learner understand the current activity without taking over their program. Approved help is instant; experimental AI is a separate adult-only lab.

OWN-WORLD: Inherit the white/lavender learning guide, violet actions, system reading type, Fredoka heading voice and approved Byte sprite. No new art, header controls or identity.

STORY: Open Ask Byte beside the instructions, choose an explanation or a program check, and return to building. Hint requests use the existing accounting; AI never supplies student answers.

FIRST VIEWPORT: A compact labelled Ask Byte disclosure within the guide, above progressive hints. Opening it reveals three readable help actions and one live answer in normal flow. Narrow screens keep the existing folded guide and stack the actions.

FORM: Precisely scoped Operate extension, no concept seed or comp required. Native disclosure, keyboard focus, local-only program inspection, no chat history persistence. The adult lab exposes off/forbidden/loading/failure/rejected/answer states with explicit experimental copy.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
