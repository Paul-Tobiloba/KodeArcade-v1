# Family portal — existing account-world extension

## Direction contract

THESIS: A parent can create a child's private home identity, hand over a login card, and see saved learning without entering the child's session.

OWN-WORLD: Preserve the approved illustrated island backdrop, K symbol, Fredoka headings, white panels, violet actions and system reading type. Reuse existing artwork; no new visual identity.

STORY: Set up a family, add a child without email, download the private card, choose courses, then review real saved progress. School-pupil linking is explicitly separate.

FIRST VIEWPORT: Family portal heading and Add child action, selectable children on the left and the selected child's courses/progress on the right. Empty state offers one clear first action. Mobile stacks selection and detail with no horizontal page overflow.

FORM: Precisely scoped extension of approved family reference. Honest zero-progress states, private one-time credentials, explicit adult sign-out before child login, accessible forms and semantic progress/quiz tables. Keep destructive access changes explained and reversible.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
