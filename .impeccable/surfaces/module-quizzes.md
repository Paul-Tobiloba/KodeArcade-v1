# Module quizzes

Mode: Operate / Read. Extend the existing learning interface; no new visual world or artwork.

## Direction contract

THESIS: Every module ends with a real five-question topic check, not another route exercise. Students can review explanations and retry without losing their best result.

OWN-WORLD: Inherit the learning violet, white reading surface, dark ink, Fredoka headings and Segoe UI controls. Use native radio groups, existing primary/secondary buttons and visible focus.

STORY: Find the quiz after activities or in the module drawer; answer all questions, submit, understand mistakes, then retry or continue. Drafts and results follow the existing account save status.

FIRST VIEWPORT: A bounded reading column presents module title, question count, untimed instructions and the first full radio group. Subsequent questions flow vertically; the submit action follows the final answer. Mobile uses the same reading order without horizontal scrolling.

FORM: Code-led local extension, no seed required. Semantic fieldsets and inline feedback, no modal or timer. Teacher reports show separate quiz results rather than conflating them with challenge stars.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
