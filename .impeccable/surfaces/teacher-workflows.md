# Classroom workflow and recovery extension

Mode: Operate. Ordinary code-led extension; retain DESIGN.md and existing account/learning layouts, original K, Fredoka headings, native fields and purple/lavender controls. No new artwork.

## Direction contract

THESIS: Teachers can prepare a class in one reviewed batch; students can recover interrupted work without exposing another child's draft.

OWN-WORLD: Reuse account tables, progressive details, notices and primary/secondary buttons. Keep utility copy in the incumbent system font.

STORY: CSV template → choose file → local row/error preview → confirm import and download private cards. Select roster students → explicit reset warning → one private PDF booklet. Course choices stage until Save assignments; explain removal preserves progress but removes access.

FIRST VIEWPORT: Existing class header and progress report stay unchanged. Import sits next to Add student. Selection controls stay beside the roster; course assignment actions stay below their labelled choices. Routine activity save status is a single compact bottom-corner toast without moving learning content or intercepting clicks, then success disappears after three seconds. Errors and recovery/conflict actions stay in a persistent in-flow strip. Reduced motion removes spatial movement.

FORM: Inherit the existing surface (no seed needed for this narrow extension). Native file/checkbox controls and bounded tables stack/wrap on phones. Signature interaction is reviewed preview before any bulk write; recovery is quiet until an unsynced/conflicting state needs attention.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
