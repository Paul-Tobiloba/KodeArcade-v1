## Users and purpose

Beginners learn through Grades 1–6 and Computer Explorers. Grades 1–2 use arrows; Grades 3–4 use text blocks; Grades 5–6 offer blocks or bounded Python-style typed commands. Larger boards and route projects remain. Suggested ages run from 6–7 in Grade 1 to 11–12+ in Grade 6; readiness determines placement. ## Stack

React, TypeScript, Vite, and Blockly. User explicitly requested drag-and-drop with three areas: execution stage, draggable block palette, and code canvas. Support mouse on computers and touch on phones/iPads. Programs are interpreted as bounded movement instructions, without eval.
